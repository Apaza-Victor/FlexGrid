Profundiza en Flexbox

flex-grow

Define cuanto crece un item respecto a sus hermanos. Si todos valen 1, se reparten el espacio equitativamente. Si uno vale 2, ocupa el doble.

flex-grow: 1; /* Los items se reparten el espacio */ flex-grow: 0; /* El item mantiene su tamano fijo */ flex-grow: 2; /* Este item crece el doble que los demas */

flex-shrink

Define cuanto se encoge un item cuando no cabe. Por defecto es 1 (se encoge). Si es 0, el item no se encoge nunca.

flex-shrink: 1; /* Se encoge normalmente */ flex-shrink: 0; /* Nunca se encoge, mantiene su tamano */

order

Cambia el orden visual de los items sin tocar el HTML. Por defecto todos valen 0. Valores negativos van primero, positivos despues.

order: -1; /* Va primero */ order: 0; /* Orden normal (defecto) */ order: 1; /* Va despues */

align-self

Sobreescribe align-items para un item individual. Permite alinear un item distinto a los demas en el eje cruz.

align-self: center; /* Solo este item se centra */ align-self: flex-end; /* Solo este item va al fondo */

flex shorthand

Atajo para flex-grow, flex-shrink y flex-basis en una sola linea. El mas usado es flex: 1 que equivale a flex: 1 1 0%.

flex: 1; /* flex: 1 1 0% - crece y encoge */ flex: 0 0 200px; /* ancho fijo de 200px */ flex: 1 1 auto; /* basado en el contenido */

Centrado perfecto con Flexbox

La forma mas rapida de centrar un elemento tanto horizontal como verticalmente.

.container { display: flex; justify-content: center; align-items: center; min-height: 100vh; }

Resumen Rapido

flex-direction

Define la direccion del eje principal. row = horizontal, column = vertical.

justify-content

Alinea los items en el eje principal del container.

align-items

Alinea los items en el eje transversal (cruz).

flex-wrap

Controla si los items saltan de linea o se mantienen en una sola.

gap

Espacio entre items. Reemplaza los margins con blood hacks.

align-content

Alinea lineas cuando hay wrap (multiples lineas de items).

flex-grow

Cuanto crece un item. 0 = fijo, 1+ = compite por espacio.

flex-shrink

Cuanto se encoge. 0 = nunca, 1+ = se encoge proporcionalmente.

order

Cambia el orden visual. Negativos primero, positivos despues.

align-self

Sobreescribe align-items para un item individual.
