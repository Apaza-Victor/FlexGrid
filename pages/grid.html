Profundiza en CSS Grid

Unidades fr

fr = fraccion del espacio disponible. Es como un flex-grow pero para grid. 1fr 2fr 1fr significa que la columna del medio ocupa el doble.

grid-template-columns: 1fr 2fr 1fr; /* 25% - 50% - 25% */ grid-template-columns: repeat(3, 1fr); /* 3 columnas iguales */

minmax()

Define un tamano minimo y maximo. Perfecto para grids responsive sin media queries.

grid-template-columns: repeat(auto-fill, minmax(250px, 1fr)); /* Columnas de min 250px, se ajustan solas */

grid-template-areas

Nombra las areas del grid con strings. Ideal para layouts complejos con nombre descriptivos.

.container { grid-template-areas: "header header header" "sidebar main main" "footer footer footer"; } .header { grid-area: header; } .sidebar { grid-area: sidebar; } .main { grid-area: main; } .footer { grid-area: footer; }

grid-auto-flow

Controla como se colocan los items automaticamente. row (defecto), column, o dense (rellena huecos).

grid-auto-flow: dense; /* Rellena huecos automaticamente */ grid-auto-flow: column; /* Llena por columnas en vez de filas */

grid-column / grid-row

Hace que un item ocupe multiples celdas. span N = ocupa N celdas.

.item-1 { grid-column: 1 / 3; /* De la linea 1 a la 3 (2 columnas) */ grid-row: span 2; /* Ocupa 2 filas */ }

Grid vs Flexbox - Cuando usar cada uno

Flexbox = un eje (fila O columna). Grid = dos ejes (fila Y columna). Usa Grid para layouts de pagina, Flexbox para componentes.

/* Flexbox: una fila de botones */ .navbar { display: flex; gap: 8px; } /* Grid: layout de pagina completo */ .page { display: grid; grid-template-columns: 250px 1fr; grid-template-rows: auto 1fr auto; }

Resumen Rapido

grid-template-columns

Define las columnas con fr, px, %, minmax() o repeat().

grid-template-rows

Define las filas. Puede ser auto, fr o valores fijos.

justify-items

Alinea items horizontalmente dentro de su celda.

align-items

Alinea items verticalmente dentro de su celda.

justify-content

Alinea toda la grilla dentro del container.

grid-auto-flow

Controla como se colocan items automaticamente.

grid-auto-rows

Altura por defecto de las filas generadas automaticamente.

gap

Espacio entre columnas y filas. Reemplaza margins.
