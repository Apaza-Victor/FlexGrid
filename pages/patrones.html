Patrones de Layout

Patrones reales de CSS para interfaces modernas. Cada patron incluye un demo visual, el codigo completo y una explicacion.

1. Holy Grail Layout GRID

El clasico layout de pagina: header arriba, sidebar izquierda, contenido principal al centro, sidebar derecha, y footer abajo. Grid-template-areas lo hace trivial.

HEADER
NAV
MAIN CONTENT
ASIDE
FOOTER
HTML + CSS
.page { display: grid; grid-template-areas: "header header header" "nav main aside" "footer footer footer"; grid-template-columns: 200px 1fr 200px; grid-template-rows: auto 1fr auto; min-height: 100vh; } .header { grid-area: header; } .nav { grid-area: nav; } .main { grid-area: main; } .aside { grid-area: aside; } .footer { grid-area: footer; }

6. Sticky Footer GRID

El footer siempre queda pegado al fondo de la pagina, incluso cuando el contenido es poco. grid-template-rows: auto 1fr auto lo logra con una sola linea.

HEADER
CONTENIDO (1fr)
Este area crece para llenar el espacio.
FOOTER (siempre abajo)
HTML + CSS
.page { display: grid; grid-template-rows: auto 1fr auto; min-height: 100vh; } /* Header: auto (se ajusta al contenido) */ /* Main: 1fr (llena todo el espacio) */ /* Footer: auto (se ajusta al contenido) */ /* Con min-height:100vh, el footer nunca */ /* queda flotando si el contenido es poco. */

Cuando usar cada patron

Layout de pagina

Holy Grail, Sidebar Fijo, Sticky Footer. Usa Grid para layouts bidimensionales de pagina completa.

Componentes de nav

Navbar, Breadcrumb, Footer multi-columna. Usa Flexbox para alinear en un eje.

Colecciones de items

Card Grid, Gallery, Pricing Table. Grid para layouts de grilla, Flexbox para filas simples.

Centrado

Flexbox: justify + align center. Grid: place-items center (2 propiedades).

Responsive

Grid: auto-fill + minmax para grillas sin media queries. Flexbox: flex-wrap para items que saltan de linea.

Alineacion cruzada

Grid: alinea en ambos ejes a la vez. Flexbox: justify en el eje principal, align en el cruz.

Construido para aprender. Modifica, experimenta y domina Flexbox & Grid.
